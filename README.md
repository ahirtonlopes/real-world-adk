# Real World Design with Agent Development Kit (ADK)

Repositório oficial com os materiais, exemplos e referências utilizados na apresentação e workshop **“Real World Design with Agent Development Kit (ADK)”**, focado na construção de agentes de IA modernos utilizando o ecossistema Google, incluindo **ADK**, **MCP (Model Context Protocol)** e arquiteturas **multiagentes**.

O conteúdo explora desde os fundamentos de agentes de IA até arquiteturas mais avançadas para sistemas autônomos capazes de utilizar ferramentas, acessar APIs, colaborar entre múltiplos agentes e operar em cenários reais de produção.

- Introdução prática a AI Agents

- Casos de uso reais e workflows supervisores
- Demonstrações com Google Agent Development Kit (ADK)
